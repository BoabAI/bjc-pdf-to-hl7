WHAT IT DOES

The tool converts patient PDF documents (consent forms, GP referrals, and specialist referral letters) into HL7 files that can be imported directly into Genie. It reads the patient details from the PDF automatically — no manual data entry required.


DATA PRIVACY & SECURITY

A few key points on how patient data is handled:

• All data stays in Australia — the application is hosted on AWS in the Sydney region
• No patient data is stored on the server — PDFs are processed entirely in memory and discarded immediately after conversion. Nothing is saved, logged, or retained
• Access is password-protected and all connections are encrypted via HTTPS
• The system simply reads the PDF, extracts the patient details, generates the HL7 file, and that's it — no data touches a database or file system
