  1. EXECUTIVE SUMMARY
================================================================================

SMEC AI has developed a web-based tool that converts patient PDF documents into
HL7 v2.4 messages compatible with Genie clinical software. The tool eliminates
manual data entry by automatically extracting patient information from PDF
documents and packaging them into the correct electronic format for import into
your practice management system.

In plain terms: staff upload a PDF, the system reads the patient details, and
produces a file that Genie can import directly - with the original PDF attached.

================================================================================
  2. PROBLEM STATEMENT
================================================================================

BJC Health receives patient documents in PDF format (consent forms, referral
letters from GPs and specialists). To get these into Genie, staff currently
need to:

  1. Open the PDF and read the patient details
  2. Manually match/enter the patient in Genie
  3. Attach the document to the correct patient record

This process is time-consuming, error-prone, and creates a bottleneck in
clinical workflow.

================================================================================
  3. SOLUTION OVERVIEW
================================================================================

The PDF to HL7 Converter is a secure web application that:

  - Accepts PDF uploads via drag-and-drop or file browser
  - Automatically detects the document type
  - Extracts patient demographics (name, DOB, sex, Medicare, address, phone)
  - Generates a standards-compliant HL7 v2.4 ORU^R01 message
  - Embeds the original PDF as a Base64 attachment within the HL7 message
  - Produces a downloadable .hl7 file ready for Genie import

The entire process takes seconds and requires no technical knowledge.

================================================================================
  6. HL7 OUTPUT SPECIFICATION
================================================================================

  Standard:            HL7 v2.4
  Message Type:        ORU^R01 (Observation Result)
  Target System:       Genie (Australian clinical software)
  Character Set:       8859/1
  Country Code:        AUS

  Segments Generated:
  -------------------
  MSH   Message Header (sender, receiver, timestamp, message type)
  PID   Patient Identification (name, DOB, sex, address, Medicare)
  PV1   Patient Visit (Outpatient class, optional doctor routing)
  OBR   Observation Request (document title, result status)
  OBX   Observation Result (original PDF embedded as Base64)

  Medicare Format:     <number>-<ref>^^^Medicare^MC
  Date Format:         YYYYMMDD (converted from Australian DD/MM/YYYY)
  Segment Terminator:  CR only (per HL7 specification)
  PDF Encoding:        Base64 in OBX-5 ED datatype (^application^pdf^Base64^)

================================================================================
  7. GENIE INTEGRATION OPTIONS
================================================================================

The converter provides two options that control how Genie handles the imported
document:

  Option                 Description                          Default
  ---------------------  -----------------------------------  --------
  Auto-file              Automatically files the document     ON
                         to the patient record (OBR-25 = F
                         for Final). When OFF, the document
                         is queued for manual review
                         (OBR-25 = P for Preliminary).

  Send to Doctor         Routes the document to a specific    OFF
                         doctor's inbox using their Medicare
                         Provider Number (placed in PV1-9).

================================================================================
  8. SECURITY & ACCESS CONTROL
================================================================================

  - Password-protected access (shared application password)
  - Authentication via secure httpOnly cookie (7-day session)
  - All PDF processing occurs in-memory (no files stored on server)
  - HTTPS encryption in transit (AWS-managed SSL)
  - No patient data is stored, logged, or retained after conversion

================================================================================
  10. HOW TO USE
================================================================================

  Step 1:  Navigate to the application URL in your web browser
  Step 2:  Enter the access password
  Step 3:  Drag and drop a PDF (or click "Browse Files")
  Step 4:  The document type is auto-detected (override if needed)
  Step 5:  Configure options:
             - Auto-file ON/OFF
             - Optionally enter a doctor's Provider Number
  Step 6:  Click "Convert to HL7"
  Step 7:  Review the extracted patient details shown on screen
  Step 8:  Click "Download HL7 File"
  Step 9:  Import the .hl7 file into Genie

================================================================================
  11. CURRENT LIMITATIONS (POC)
================================================================================

  - Only processes one PDF at a time (no batch upload)
  - Requires the PDF to contain machine-readable text (not scanned images)
  - Document type detection relies on specific formatting conventions
  - Patient sex is inferred from title (Mr/Mrs/Ms) or pronoun analysis
    when no title is available
  - No direct Genie integration (manual .hl7 file import required)
